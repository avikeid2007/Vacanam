Decoupled Architecture

How Vacanam Works

A pipeline designed for ultra-low latency, zero data loss, and seamless text injection.

1

Global Hotkey & Foreground App Detection

Win32 RegisterHotKey captures Ctrl+Space and resolves the target application's HWND and process name (VS Code, Chrome, etc.).

2

WASAPI Audio Capture & Conversion

Low-overhead WASAPI audio streaming with pure managed C# 16kHz mono resampling without any native COM or MediaFoundation dependencies.

3

VAD Silence Trimming & Whisper STT

Energy-based Voice Activity Detection trims leading/trailing silence before executing multi-threaded Whisper.net inference.

4

(Optional) Local LLM Text Polish

LLamaSharp processes the raw transcript through local GGUF models (Qwen 2.5 / Llama 3.2) with your custom grammar rules.

5

Smart Text Injection & SQLite History

Injects final text directly at the cursor via Clipboard or SendInput, and saves an opt-in audit log to local SQLite.

Frequently Asked Questions

Got Questions?

Everything you need to know about Vacanam, privacy, and system requirements.

Does Vacanam require an Internet connection?
No. Once the initial speech model is downloaded, Vacanam runs 100% offline. All speech recognition and AI text refinement execute directly on your local CPU or GPU.
Do I need a dedicated GPU (NVIDIA RTX)?
No. Vacanam is heavily optimized for multi-threaded CPU inference. The Ultra Fast (tiny) and Balanced (small) models run smoothly on standard laptops with Intel/AMD processors. CUDA acceleration is available if you have an NVIDIA GPU.
Why does Windows SmartScreen show a warning when installing?
Vacanam is a free, open-source application built with GitHub Actions. Because it does not use an expensive commercial EV Code Signing certificate, Windows Defender SmartScreen displays a standard informational prompt. Click More info → Run anyway to install safely.
Can I change the global hotkey?
Yes! Open Vacanam Settings from the System Tray icon to configure your preferred shortcut and toggle Push-to-Talk vs Toggle recording modes.
Is my dictation history private?
Yes, 100%. History recording is completely opt-in and disabled by default. When enabled, records are saved exclusively to a local SQLite database in your %LOCALAPPDATA%\Vacanam\ folder.
